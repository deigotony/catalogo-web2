caminho normal de uma interação que um usuário faz:
usuário interage via HTML -> JS manda requisição HTTP -> routes -> controller -> service -> repository -> model -> SQLite -> (operações no banco de dados)

app.js: configura middleware e rotas do express (exemplo: app.use(/usuarios, usuariosRoutes))
server.js: importa app.js; roda o servidor em uma porta (app.listen(3000, ()=>{...}))

testes:
testes com transações (para dar rollback)
testar cada camada descrita anteriormente, começando do mais baixo até o mais em cima
configurar o package.json para rodar a suite de testes
(por ora estamos usando códigos HTTP de erro genéricos (400))

mudanças:
tirar as rotas de server.js e jogar para as camadas de routes e services
substituir dados JSON por banco de dados (SQLite3 + Sequelize) e fazer as devidas adaptações no resto do código
